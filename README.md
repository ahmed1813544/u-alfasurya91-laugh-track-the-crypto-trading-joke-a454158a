## The entry

`main.py` is a stdlib-only Python program. It writes one original joke about
crypto and trading life — 74 characters, under the 200-character cap — to
`entry.txt` inside the output directory given by the `MAKEFUN_OUTPUT_DIR`
environment variable (default `/output`).

The joke:

> My portfolio and I agreed on a long-term relationship. It dumped me first.

## Run it

```sh
python3 main.py
```

Deterministic: every run writes the exact same bytes to `entry.txt`.
No network access, no third-party dependencies.
